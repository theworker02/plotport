# plotport

Plot structured JSON port payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/plotport/

## Install / run

```bash
git clone https://github.com/theworker02/plotport.git
cd plotport
node src/cli.js
node --test
```
